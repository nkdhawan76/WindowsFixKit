## 🛠️ Step-by-Step Action Plan

### 1. ⚡ Quickdraw (Fastest: < 2 Minutes)
1. Go to [WindowsFixKit Issues](https://github.com/nkdhawan76/WindowsFixKit/issues).
2. Click **New Issue** → Title: `test: verification of issue lifecycle`.
3. Submit the issue.
4. Immediately scroll to the bottom and click **Close with comment** or **Close issue**.
5. *Result: Quickdraw badge appears on your profile within a few minutes!*

---

### 2. 👥 Pair Extraordinaire (With Co-Author)
When committing in Git, add the `Co-authored-by` footer at the end of the commit message (with an empty line separating the body):

```bash
git commit -m "docs: add guide for unlocking github achievements

Co-authored-by: Nikil Dhawan <devsparksindia@gmail.com>
Co-authored-by: DevSparks Support <9521032268@devsparksindia.com>"
```

---

### 3. 🦈 Pull Shark (Leveling Up to Gold) & 🤠 YOLO
1. Create a new branch:
   ```bash
   git checkout -b docs/achievements-guide
   ```
2. Commit your updates and push the branch:
   ```bash
   git push origin docs/achievements-guide
   ```
3. On GitHub, click **Compare & pull request**.
4. Click **Create Pull Request**, then immediately click **Merge Pull Request** → **Confirm Merge**.
5. *Result: Increments your Pull Shark count and unlocks/upgrades YOLO!*

---

### 4. 🧠 Galaxy Brain (Q&A Discussions)
1. Go to repository **Settings** → Scroll to **Features** → Check **Discussions**.
2. Click the new **Discussions** tab → Click **New Discussion** → Select **Q&A**.
3. Ask a common troubleshooting question (e.g., *"How to fix Windows Update 0x80070005 error?"*).
4. Reply with the solution using WindowsFixKit commands.
5. Click the **Mark as answer** checkmark (✓) on the reply.
6. *Repeat twice to trigger the Galaxy Brain achievement!*
